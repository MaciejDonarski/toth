# `@toth/eslint-config`

Shared ESLint flat configs.

| Export                               | Use for                                                   |
| ------------------------------------ | --------------------------------------------------------- |
| `@toth/eslint-config/base`           | Plain TypeScript packages (`@toth/utils`)                 |
| `@toth/eslint-config/react-internal` | React libraries (`@toth/ui`, `@toth/form`, `@toth/table`) |
| `@toth/eslint-config/next-js`        | Next.js apps. Also exports `hexagonalBoundaries`.         |
